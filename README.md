# remnawave-cdn

Интерактивный скрипт настройки CDN (4G) для нод Remnawave.

Принцип тот же, что у нод панели: инбаунд в профиль ноды → включить на ноде → сквад → хост в подписку.

## Что делает

- сохраняет URL и токен панели
- сохраняет данные нод: адрес, SSH, порт origin, домен CDN
- мастер с вопросами на каждом шаге и меню выбора
- диагностика CDN и origin
- исправления на лету и из меню

## Запуск

```bash
chmod +x remnawave-cdn.sh
./remnawave-cdn.sh
```

Нужны `curl` и `jq`. Для применения nginx по SSH — `sshpass`.

Данные лежат в `~/.config/remnawave-cdn/`:

- `config.env` — панель
- `nodes.json` — ноды

При первом запуске спросит URL панели и токен. Поменять или удалить можно из меню.
